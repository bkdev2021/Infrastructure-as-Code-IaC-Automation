# Infrastructure-as-Code-IaC

****What is Terraform ****
Terraform is a tool that automates the setup of cloud resources like servers, databases, and networks. Instead of clicking buttons in AWS, Azure, or Google Cloud, write a simple script (just like a blueprint).
Terraform is an infrastructure as code tool  that builds and manages your cloud infrastructure (servers, databases, networks) by reading instruction manuals you write.

****How it Work****
Terraform creates and manages resources on cloud platforms and other services through their application programming interfaces (APIs). Providers enable Terraform to work with virtually any platform or service with an accessible API.

****What is API****
An API (Application Programming Interface) is a set of rules and protocols that allows different software systems to communicate with each other. It defines:

Endpoints - Specific URLs/paths to access functionality
(Example: https://api.example.com/users)

Request Methods - Actions you can perform:
    GET - Retrieve data
    POST - Create data
    PUT/PATCH - Update data
    DELETE - Remove data

Request/Response Format - Typically uses:
    JSON (most common)
    XML
    Protocol Buffers
